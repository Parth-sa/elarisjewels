# Elaris Jewels

## 3D Models (GLB)

`glbs/` contains **2,184 GLB 3D renders** — the 2.00 ct (200ct) 3D model for every engagement ring, one per shape.

Naming: `BE<CODE>_<SHAPE>_200ct_RENDER.glb`

Shape codes: AS (Asscher), CU (Cushion/Old Mine), EM (Emerald), HT (Heart), MQ (Marquise), OV (Oval), PE (Pear), PR (Princess), RA (Radiant), RD (Round)

### Reference files

- `EngagementRings_200ct_GLB_List.csv` — GLB path + URL handle + shape for every 200ct model
- `EngagementRings_200ct_GLB_List.xlsx` — same as CSV in Excel format
