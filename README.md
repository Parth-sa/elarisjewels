# Elaris Jewels

## 3D Models (GLB)

### Engagement rings — `glbs/`

Contains **2,184 GLB 3D renders** — the 2.00 ct (200ct) 3D model for every engagement ring, one per shape.

Naming: `BE<CODE>_<SHAPE>_200ct_RENDER.glb`

Shape codes: AS (Asscher), CU (Cushion/Old Mine), EM (Emerald), HT (Heart), MQ (Marquise), OV (Oval), PE (Pear), PR (Princess), RA (Radiant), RD (Round)

Reference files:

- `EngagementRings_200ct_GLB_List.csv` / `.xlsx` — GLB path + URL handle + shape for every 200ct model
- `EngagementRings_200ct_GLB_PublicURLs.csv` / `.xlsx` — direct download URLs

### Wedding bands — `wedding_glbs/`

Contains **497 GLB 3D renders** — one render per wedding band product.

Naming: `BE<CODE>_RENDER.glb`

Reference files:

- `WeddingRings_GLB_List.csv` / `.xlsx` — code, title, handle, collection, metals, GLB path, size
- `WeddingRings_GLB_PublicURLs.csv` / `.xlsx` — direct download URLs (raw + GitHub blob)

## Direct download URL format

Engagement 200ct:

```
https://raw.githubusercontent.com/Parth-sa/elarisjewels/main/glbs/<FILENAME>
```

Wedding bands:

```
https://raw.githubusercontent.com/Parth-sa/elarisjewels/main/wedding_glbs/<FILENAME>
```
